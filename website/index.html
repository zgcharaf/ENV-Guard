Your build failed.

“Works on my machine” isn’t a diagnosis. EnvGuard CI connects Python interpreter identity, installed packages and runtime differences to explain supported CI failures with evidence—not guesswork.

THE HARD PART ISN'T INSTALLATION.

It's proving which environment ran, what changed, and what the evidence actually supports.

01 / THE PROBLEM

Same error.
Different root causes.

ModuleNotFoundError could mean the dependency was never installed, another virtualenv ran the command, or Python startup flags hid site-packages. A package list alone can’t tell you which.

01 /

Execution provenance

Record the directly invoked Python executable and compare it to the explicitly intended environment.

02 / HOW IT WORKS

From red pipeline
to a reasoned answer.

01

Wrap your existing command

Keep pip, uv, Poetry and your CI setup. EnvGuard executes the command you specify and preserves its exit status.

02

Collect runtime evidence

Capture runtime metadata and correlate the observed failure with a known-good snapshot when available.

03

Investigate with clarity

Read the incident dossier: what happened, what the evidence supports, what remains unknown and what to check next.

03 / QUICK START

Useful in minutes.
No platform migration.

Install from source for this release candidate. The package has not been claimed as a public PyPI release.

git clone https://github.com/zgcharaf/ENV-Guard.git
cd ENV-Guard
python -m pip install -e .
envguard-ci --version

04 / TRUST BY DESIGN

Evidence first.
Certainty earned.

Engineering tools should be clear about what they know—and what they don't.

Read the security policy ↗
✓

Local-first

No EnvGuard cloud backend or automatic telemetry required for local diagnostics.

✓

No silent repair

Candidate interpreter experiments require explicit permission; source and dependency files aren't auto-modified.

✓

Explicit uncertainty

A missing import is not automatically attributed to a particular package or environmental change.

!

Real limitations

Not a sandbox. Doesn't trace arbitrary child Python processes. CI artifacts can include sensitive package metadata and require restricted access. Independent accuracy benchmarking is pending.
